# 出图前后最小验收

## 内容 QA（出图前，最重要）

- [ ] 主问题与读者定位明确；每个视觉区块支持一个明确的理解目标。
- [ ] 原文明确内容与推断/未确认信息分开；没有“可能支持”变成“已经支持”。
- [ ] 角色、箭头方向、时间顺序、状态、例外路径与原文一致。
- [ ] 金额、版本、日期、端口、API 字段、条件、比较维度正确；无杜撰。
- [ ] 类比后的真实机制与类比边界仍然正确。
- [ ] 发送至第三方图像生成服务的提示词已经脱敏，不包含秘密/个人资料。

## 图像 QA（出图后，只检查真实图片）

- [ ] 输出图片文件实际存在、能打开、是非空位图；不得仅检查提示词。
- [ ] 中文没有明显错字、乱码、漏字、重复字；重要技术词和数字完全正确。
- [ ] 阅读路径直观：标题 → 要点 → 例子/机制 → 结论。
- [ ] 主要视觉是关系/动作/流程，不是用五颜六色卡片包裹长段文字。
- [ ] 没有截断、模糊、重叠、连线交叉误导、过小字体。
- [ ] 符合用户指定的比例、风格、图数；多图保持一致。

## 失败时处理

- 事实错误、箭头错误、关键中文错字：必须改 prompt 重绘受影响的图；不做图片覆盖文字的程序化修补。
- 图像模型反复写错长中文：缩短标签、拆分多图、减少文本密度，并保留完整准确解释在 `outline.md`。
- 工具无法用或读取来源失败：报告限制并交付可复用提示词，不声称已经有最终 PNG。
