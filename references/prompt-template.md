# 可直接送给图片生成模型的提示词模板

模板中的占位内容必须用真实资料填写。完成前删除所有 `{占位符}` 和与主题无关的句子。

```text
生成 1 张完成度高、内容准确、中文字形可读的原创中文科普信息图。最终交付 PNG 位图，不是 HTML、SVG、网页、幻灯片或摄影海报。

主题：{主题}
受众：{零基础读者 / 用户指定受众}
核心记忆句（必须准确表达）：{一句话}
画幅：{4:5，或用户指定比例}
主结构：{竖版分区科普 / 流程 / 对比 / 架构 / 时间线}
视觉风格：{中文手绘科普、米白手账纸、马卡龙块、黑色手绘边框、暖黄色荧光笔重点、轻卡通角色；或用户指定风格}

画面分区（从上到下，或按指定阅读路线）：
① 标题与导语：主标题精确写“{中文标题}”；副标题精确写“{简短导语}”。画面象征：{清晰可视物体/人物/动作}。
② {第一块名称}：画 {画面行为、关系、输入输出}；标签只写“{短标签 A}”“{短标签 B}”。
③ {第二块名称}：画 {画面行为、关系、输入输出}；箭头从 {源节点} 指向 {目标节点}；标签只写“{短标签 C}”。
④ {第三块名称}：画 {对比、状态、实例}；标签只写“{短标签 D}”。
⑤ {必要时的限制/总结块}：画 {限制的可视化场景}；必须精确写“{关键边界或总结}”。
（按真实内容增删分区，通常 3–5 块，避免机械套版。）

准确性约束：{涉及业务判断、顺序、数字、否定条件、未证实事项、必须保留的专名和字段}
文字约束：仅使用上面列出的精确中文文字；不得自动填充小段正文、伪文字、英文水印或无来源数据。文字清晰且足够大；避免太小的说明字；专业术语拼写准确。
构图：明确的视觉阅读动线，图像和箭头承载逻辑；色块有适度留白，不拥挤，元素位置对齐，人物与设备功能有意义。
风格参考：如输入了示例图片，仅借鉴配色、手绘质感、知识卡风格和高亮语法，不复制其中的商标、角色造型、原文或具体内容。
禁止：密密麻麻长段落、装饰性假流程、文本乱码、错误箭头、文字遮挡、虚构事实、logo、水印、网页 UI 框架。
```

## 多图一致性

针对同一主题的第 2 张及以后，重复相同的调色板、背景质感、描线风格、字体视觉、图标简化程度，并在实际工具支持时传入第 1 张作为风格锚点。每张图不超过一个主要认知目标。

## 提示词写作要点

1. 将精确中文短标签单独写在“文字约束”里，避免让模型自己发明摘要文字。
2. 箭头必须写明由哪一端指向哪一端；失败与异常分支不要误画成正常完成。
3. 避免图像模型自发生成未在资料中的金额、成功率、时间、保证、承诺。
4. 有长字段/条款不宜放图时，改为简短准确的中文释义，精确术语留在 `outline.md`。
5. 只依据已实际获得的内容写提示词，不能用推测补齐来源缺失的页面。
